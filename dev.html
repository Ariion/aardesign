Ce que j'ai construit

OMC — Intranet hospitalier

en production

Application web temps réel pour la gestion d'un service hospitalier (dispatch, lits, plannings) : suivi des patients, gestion des chambres avec superposition de plans, et planning du personnel — utilisée quotidiennement par une équipe, y compris sur une tablette embarquée sur site.

  • Authentification et persistance des données via Firebase / Firestore
  • Tableau de dispatch en glisser-déposer avec sauvegarde en temps réel
  • Cartographie des chambres par coordonnées en pourcentage, calée pièce par pièce sur les plans réels
  • Migration d'hébergement pour intégration dans une tablette embarquée (en-têtes CSP/CORS spécifiques pour compatibilité Chromium)
stack: Firebase, Firestore, JavaScript
rôle: solo dev — conception, code, déploiement
contrainte notable: intégration NUI dans un environnement Chromium embarqué

AGENDA — Système de réservation

23+ PR mergées

Script de prise de rendez-vous conçu pour une distribution publique : architecture pensée dès le départ pour être installée et configurée par des tiers, pas juste pour un usage perso. Zéro configuration serveur — chaque métier (hôpital, garage, cabinet, notaire...) se déclare dans un fichier de config.

  • Vue "côte à côte" civil / soignant avec état partagé en temps réel — une réservation posée côté civil apparaît instantanément côté staff
  • Architecture multi-établissements et multi-services, filtrage par grade (ex. Scanner/IRM réservés aux médecins)
  • Disponibilités récurrentes (quotidiennes ou hebdomadaires), anti-double-réservation par verrou atomique côté serveur
  • Internationalisation, thème configurable, détection automatique du téléphone (lb-phone, qb-phone, standalone)

Procom Solution — Site vitrine

livré

Site web institutionnel pour une entreprise de services, de la conception UI à l'intégration. Le brief : une présence en ligne à la hauteur de l'image sérieuse et rassurante de la marque — pas un template générique.

  • Design de l'interface puis intégration complète en HTML/CSS/JS
  • Hiérarchie de l'information et lisibilité travaillées pour un public non technique
  • Cohérence stricte avec l'identité de marque existante (logo, palette, ton) livrée en amont
stack: HTML, CSS, JavaScript

contrainte notable: site vitrine client réel, pas un exercice — validé et livré

// Jeux

À côté, du jeu vidéo

Les Cryptes Éternelles

alpha — en dev

Roguelike heroic-fantasy bilingue (FR/EN), tout le jeu tient dans un seul fichier HTML/JS. Sauvegarde cloud et classement mondial en temps réel, packaging pensé pour une vraie distribution publique plutôt qu'un prototype jetable.

  • Sauvegarde et classement mondial via Firebase / Firestore, avec règles de validation côté serveur pour filtrer les scores aberrants
  • Progressive Web App (installable, jouable hors-ligne)
  • Pipeline de build dédié : obfuscation du code JS pour la version publique, déploiement continu via GitHub Actions vers Firebase Hosting à chaque push
stack: JavaScript, Firebase / Firestore, GitHub Actions
rôle: solo dev — game design, code, infra de déploiement
contrainte notable: tout le jeu (moteur, UI, sauvegarde) tient dans un seul fichier HTML, pensé pour rester distribuable et copiable-collable

Horde de Chats

alpha — dev local

Prototype de jeu 3D dans le navigateur, jouable sur mobile. Plusieurs modes de jeu autour d'une horde de chats à faire grandir et défendre, avec un vrai rendu 3D temps réel plutôt qu'un jeu en 2D classique.

  • Rendu 3D temps réel avec Three.js (scène, caméra, post-traitement visuel)
  • Plusieurs modes de jeu distincts (tower defense, moulin, puzzle) partageant le même moteur
  • Système de biomes, boutique in-game, interface tactile pensée mobile-first
stack: JavaScript, Three.js (WebGL)
rôle: solo dev — game design, rendu 3D, gameplay
contrainte notable: encore en développement local, pas de version publique pour l'instant
